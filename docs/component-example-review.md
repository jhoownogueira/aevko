# Component example reference review

Reviewed on 2026-11-03 against the public Zard UI documentation. This is an example and interaction review, not a claim of API or pixel parity. Aevko preserves its square, neutral design contract and canonical Angular source.

The table records the reference examples observed and the implemented Aevko examples. Each local example includes its complete standalone TypeScript, styles, imports and installation dependencies. The displayed source and live component are generated from the same definition in `apps/docs/examples/catalog.mjs`.

Zard documents some capabilities that Aevko does not currently implement: calendar range/multiple selection, select multi-selection, nested menus and toast promises. These are not represented as supported APIs. The additional Aevko-only components use related form, layout or composition patterns; their missing Zard URLs redirect to the home page.

## Verification

Browser coverage is maintained in `tests/browser/component-examples.mjs`. It checks all 131 examples across desktop/mobile and light/dark themes, including axe, overflow and runtime errors. Interaction coverage is maintained separately to exercise open surfaces, keyboard dismissal, controlled actions and disclosure motion. Screenshots and raw results are written under `tmp/examples-audit` and are not release status evidence by themselves.

Chart examples were expanded on 2026-11-04. See [Charts and blocks](charts-and-blocks.md) for the renderer contract and verification.
