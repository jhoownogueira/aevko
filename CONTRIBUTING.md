# Contributing

Use Node and pnpm versions declared in `package.json`, run `pnpm install`, and
keep changes focused. A component change must include registry metadata,
documentation and relevant tests. Run `pnpm format:check`, `pnpm test`,
`pnpm build` and the isolated consumer smoke test before opening a pull request.

Do not replace versioned brand assets without design approval. Report accessibility
regressions as bugs and include the keyboard path, browser and assistive technology
when known.
